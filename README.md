# Kinect_Videojuego_Letras
Es un juego de formar palabras controlado con Kinect (modo de pie) o con mouse. En pantalla aparece una pista (arriba), ranuras para la respuesta (centro) y una bandeja de letras (abajo-izquierda). Con la mano (o el cursor) “tomas” una letra, la arrastras y la sueltas sobre la ranura correcta.
